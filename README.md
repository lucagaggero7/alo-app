# ALO - Sistema de Turnero Médico (Frontend)

Aplicación web para la gestión de turnos médicos, desarrollada con **Next.js 14**, **TypeScript**, **Tailwind CSS** y **React Hook Form**. Consume la API REST de ALO.

## 📋 Requisitos

- Node.js 18.17.0+
- npm 9.0.0+ o yarn 1.22.0+
- Backend FastAPI corriendo en `http://localhost:8000`

## 🛠️ Instalación

### 1. Clonar el repositorio

```bash
git clone https://github.com/lucagaggero7/alo-app.git
cd alo-app
```

### 2. Instalar dependencias

```bash
npm install
```

### 3. Crear un archivo `.env.local` en la raíz del proyecto:

```env
NEXT_PUBLIC_API_URL=http://localhost:8000
```

### 4. Ejecutar en modo desarrollo

```bash
npm run dev
```
- **Aplicación:** http://localhost:3000
